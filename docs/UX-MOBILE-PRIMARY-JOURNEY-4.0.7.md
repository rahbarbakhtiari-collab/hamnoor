# Hamnoor 4.0.7 — Mobile primary journey hierarchy

The mobile dashboard now renders the generic `hamnoor_dashboard_summary_extension` after Hamnoor core actions. This keeps the product hierarchy focused on participation:

1. Personal Quran continuation (when present)
2. Current/next share reading
3. Core status and quick actions
4. Pending shares
5. Optional secondary integrations such as Rewards and Referral

Desktop placement is unchanged. The same mobile placement applies to embedded/Eitaa app surfaces because they use the mobile dashboard presentation. No DB schema or domain behavior changes.
