# هسته قرآن مناهل — نسخه آزمایشی 0.1.0

این افزونه برای آزمایش روی `babani.ir` ساخته شده است و هیچ برگه عمومی ایجاد نمی‌کند.

## داده‌ها
- متن عربی: ۶۲۳۶ آیه از جدول ارائه‌شده `quran_text`
- ترجمه فارسی: ۶۲۳۶ آیه از جدول ارائه‌شده `fa_makarem`
- متادیتا: Tanzil Quran Metadata v1.0
- تقسیم‌بندی‌ها: ۱۱۴ سوره، ۳۰ جزء، ۲۴۰ ربع حزب، ۷ منزل، ۵۵۶ رکوع، ۶۰۴ صفحه و ۱۵ سجده

## نصب آزمایشی
1. افزونه را در وردپرس `babani.ir` نصب و فعال کنید.
2. به «ابزارها ← هسته قرآن مناهل» بروید.
3. «شروع/ادامه واردسازی» را بزنید.
4. پس از رسیدن شمارنده به ۶۲۳۶، آیه ۲:۲۵۵ را آزمایش کنید.

## نمونه PHP
```php
$verse = manahel_quran_core()->get_verse(2, 255);
```

## نمونه REST
`/wp-json/manahel-quran/v1/verse/2/255`

این نسخه هنوز رابط عمومی قرآن و قابلیت ثبت پیشرفت هم‌نور را اضافه نمی‌کند.
