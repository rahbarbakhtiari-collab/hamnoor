# Manahel Rewards 0.8.1

## Reward Catalog UX
- سه وضعیت روشن: قابل دریافت، نزدیک، دور/ناموجود.
- فیلترهای قابل دریافت، نزدیک‌ترین، کد/شارژ و محصولات فیزیکی.
- مرتب‌سازی بر اساس امکان دریافت و فاصله امتیازی.
- Progress تا جایزه و نمایش امتیاز باقی‌مانده.
- اتصال فاصله تا جایزه به دعوت موفق برای رشد ویروسی.
- تأیید دریافت در Bottom Sheet با نمایش موجودی قبل/بعد.
- دسکتاپ سه‌ستونه و موبایل تک‌ستونه.
- بدون تغییر DB Schema یا منطق Ledger/Redemption.
