# گزارش اعتبارسنجی نسخه 1.1.0

تاریخ: 2026-07-16

## آزمون‌های انجام‌شده

- بررسی نحو تمام فایل‌های PHP با `php -l`: موفق
- بررسی نحو JavaScript با `node --check`: موفق
- آزمون تبدیل شماره‌های محلی، بین‌المللی و ارقام فارسی: موفق
- آزمون پذیرش کد ملی معتبر: موفق
- آزمون تبدیل ارقام فارسی کد ملی: موفق
- آزمون رد رقم کنترل نادرست کد ملی: موفق
- آزمون رد کدهای ملی با ده رقم یکسان: موفق
- آزمون نمایش پوشیده کد ملی: موفق
- آزمون تولید نام کاربری با پیشوند `mn_`: موفق
- آزمون عدم وجود شماره موبایل در نام کاربری جدید: موفق
- بررسی مهاجرت نام تنظیم قدیمی بستن ورود رمزی: انجام شد
- بررسی عدم وجود API Key واقعی یا کلید اضطراری واقعی در بسته: موفق
- بررسی سلامت فایل ZIP: موفق

## آزمون‌های نیازمند محیط واقعی وردپرس

- ارسال پترن با حساب واقعی IPPanel
- ثبت شماره موبایل مدیر از صفحه شناسنامه
- ورود مدیر با OTP و دسترسی به `/wp-admin/`
- ثبت‌نام کاربر جدید و ذخیره کد ملی
- کنترل یکتایی موبایل و کد ملی در دیتابیس واقعی
- اتصال به LearnDash و بازگشت به صفحه دوره
- حفظ پیشرفت درس و آزمون بعد از خروج و ورود دوباره
- رفتار کش هاست و افزونه کش در برگه ورود
- ورود اضطراری مدیر با کلید تعریف‌شده در `wp-config.php`

نسخه باید ابتدا روی `e.manahel.ir` با حساب آزمایشی و سپس با حساب مدیر بررسی شود.
