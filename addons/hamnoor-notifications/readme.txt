افزونه جامع و ماژولار اعلان‌های هم‌نور.

== Description ==

این بسته واحد شامل Notification Engine، صف پایدار، Retry، گزارش تحویل، Web Push، ایتا، بله، روبیکا و جایگاه‌های آینده واتساپ، تلگرام و Push اپلیکیشن است. هر کانال ماژول داخلی مستقلی دارد و خطای آن از Bootstrap سایت خارج نمی‌شود.

همه کلیدهای تنظیمات، اشتراک‌های Web Push، اتصال کاربران پیام‌رسان‌ها و رکوردهای صف قبلی بدون تغییر استفاده می‌شوند.

== Installation ==

1. Hamnoor Core نسخه 4.0.0 را نصب یا جایگزین کنید.
2. افزونه‌های مستقل قدیمی Web Push، ایتا، بله، روبیکا و موتور اعلان alpha10 را غیرفعال کنید.
3. این بسته را نصب و فعال کنید.
4. سلامت Engine و کانال‌ها را از بخش «کانال‌های اعلان» بررسی کنید.
