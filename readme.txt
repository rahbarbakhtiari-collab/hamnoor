افزونه هم‌نور برای ایجاد و مدیریت ختم جمعی قرآن، انتخاب سهم، پیگیری مشارکت و خروجی گزارش طراحی شده است.

== Description ==

Hamnoor یک افزونه وردپرس برای ایجاد ختم جمعی قرآن است. ایجادکننده ختم می‌تواند ختم عمومی یا خصوصی بسازد، لینک اختصاصی دریافت کند، سهم‌ها را بر اساس صفحه، جزء، سوره یا تکرار یک سوره ایجاد کند و وضعیت مشارکت را ببیند.

امکانات اصلی:

* ایجاد ختم فقط برای کاربران واردشده مجاز
* لینک اختصاصی کوتاه برای هر ختم
* ختم بر اساس صفحه، جزء، سوره و ختم تکراری یک سوره
* انتخاب سهم توسط کاربران مهمان یا عضو
* پیگیری سهم‌ها با موبایل یا ایمیل
* اعتبارسنجی موبایل ایران در سمت سرور
* خروجی CSV و XLSX ایمن‌شده
* پنل مدیریت با جستجو، فیلتر، ویرایش، گزارش شرکت‌کنندگان و لاگ‌ها
* سئو پایه برای ختم‌های عمومی
* طراحی ریسپانسیو و سازگار با قالب فعال سایت

== Installation ==

1. فایل افزونه را از پیشخوان وردپرس بارگذاری و فعال کنید.
2. به‌صورت پیش‌فرض برگه‌های «ختم‌های قرآن»، «حساب هم‌نور» و «پیگیری سهم‌های ختم» ساخته می‌شوند؛ داشبورد داخل حساب هم‌نور نمایش داده می‌شود.
3. از مسیر «هم‌نور ← تنظیمات» پایه لینک، رنگ‌ها و تنظیمات سئو را بررسی کنید.
4. از داشبورد هم‌نور نخستین ختم خود را بسازید.
